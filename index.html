Connect GitHub Gist

Your cards will be saved to a private GitHub Gist and stay there forever — synced across every device and browser. Cards only disappear when you click Delete Forever.

  1. Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Click Generate new token (classic), give it any name, and check only the gist scope.
  3. Copy the token and paste it below.
